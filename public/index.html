Model Context Protocol server & connector

Provision a reproducible OpenCode workstation on any Linux box.

opencode-workbench is an MCP server that turns a bare Linux machine — local or remote over SSH — into a ready OpenCode development workstation: it scans the platform, installs the latest stable OpenCode, applies the full profile (MCP servers, agent skills, plugins, config), and verifies the result. Secrets are never read, transmitted, or written.

Quick start

1 · Local stdio

Run without installing, then point any MCP client at it.

npx -y @simonmak-ascent/opencode-workbench

2 · Remote (Streamable HTTP)

Use the hosted connector — no local install.

https://opencode-workbench.simonmak.com/mcp

Register with OpenCode (or any MCP client)

{
  "mcp": {
    "opencode-workbench": {
      "type": "local",
      "command": ["npx", "-y", "@simonmak-ascent/opencode-workbench"],
      "enabled": true,
      "timeout": 600000
    }
  }
}

Then drive a clone

inspect_target  →  plan_clone  →  apply_clone { confirm: true }  →  verify_clone

# or one call, end to end:
provision_host  { target: { mode: "ssh", host: "box", user: "me" }, confirm: true }

# see every parameter:
provision_host  { help: true }

Security posture

Secret-value-free

The connector never reads, transmits, or writes secret values. It writes an empty ~/.env.workbench (mode 600) listing only the variable names to fill in.

Consent-gated mutations

Every install/apply/remove/update returns a plan first; nothing changes until you pass confirm: true.

Value-blind credentials

Credential tools check only whether an env var is set and return acquisition guidance — never the value.

Scanned

The repository is public and gated by gitleaks and GitHub secret scanning on every push.
