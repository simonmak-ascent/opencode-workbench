# Design System

> Phase: #2 | Created: 2026-07-27

## Token Hierarchy

```
Primitive tokens (Figma Variables)
  color.blue.600, spacing.4, radius.md
         ↓
Semantic tokens (Style Dictionary)
  color.surface.brand → color.blue.600
  color.text.primary → color.neutral.950
         ↓
Component tokens (Tailwind theme)
  button.primary.bg → color.surface.brand
```

## Token Categories

### Colors
- **Surface**: `brand`, `primary`, `secondary`, `muted`, `inverted`
- **Text**: `primary`, `secondary`, `muted`, `inverted`, `link`, `error`, `success`, `warning`
- **Border**: `default`, `muted`, `focus`, `error`
- **Status**: `success`, `warning`, `error`, `info`

### Spacing
- Based on 4px grid: 4, 8, 12, 16, 20, 24, 32, 40, 48, 56, 64

### Typography
- **Scale**: xs (12px), sm (14px), base (16px), lg (18px), xl (20px), 2xl (24px), 3xl (30px), 4xl (36px)
- **Weights**: normal (400), medium (500), semibold (600), bold (700)
- **Line heights**: tight (1.25), normal (1.5), relaxed (1.75)

### Radii
- `none` (0), `sm` (4px), `md` (8px), `lg` (12px), `xl` (16px), `full` (9999px)

### Shadows
- `sm`, `md`, `lg`, `xl`, `inner`

## Component Library

Use shadcn/ui v4 components:
- **Layout**: Card, Separator, Sheet, Sidebar
- **Navigation**: Breadcrumb, Link, Pagination, Tabs
- **Inputs**: Button, Input, Select, Checkbox, Radio, Switch, Slider, Textarea
- **Data**: Table, DataTable, Chart
- **Feedback**: Alert, Dialog, Toast, Tooltip, Skeleton, Progress
- **AI-specific**: Chat bubble, Streaming text, Tool call card, Approval dialog
